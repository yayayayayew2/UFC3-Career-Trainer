## Quick Start

1. Start the game and enter **Career Mode**.
2. Open Cheat Engine and attach it to the UFC 3 process.
3. Open `UFC3_CareerMode_Trainer.CT` in Cheat Engine.
4. Press the hotkeys from the [Hotkey Reference](#hotkey-reference), or tick the entries manually in the table.
5. Check the [in-game overlay](#in-game-overlay) to confirm each feature turned on.

> Press each key **once** and wait a moment. Don't spam the keys.

## Stamina Guide

Unlimited Stamina keeps the stamina of the fighter(s) you choose at 100%. The stamina hook is installed automatically the first time you use a stamina key, so there is nothing to set up.

| Key | Result |
|---|---|
| `NUMPAD 1` | Stamina locked for the **LEFT** fighter |
| `NUMPAD 2` | Stamina locked for the **RIGHT** fighter |
| `NUMPAD 3` | Stamina locked for **BOTH** fighters |
| `NUMPAD 0` | Stamina lock **OFF** (reset) |

- Pick the side your fighter is on. Pressing a different stamina key switches the mode.
- Press the **same key again** to turn the stamina lock off.
- `NUMPAD 0` always turns the stamina lock off completely.

> [!TIP]
> Not sure which side you are on? Press `NUMPAD 3` to lock both fighters.

The table also shows **Lock Status** and **Target Fighter** so you can see the current stamina mode.

## In-Game Overlay

The overlay is built to stay out of your way:

- **Feature box.** Every time you press a key, a box appears in the top-left corner of the screen. It lists each feature, its hotkey, and an **ON / OFF** badge. It hides itself after a few seconds.
- **Active bar.** A bar under the box lists the features that are currently active. It stays on screen for as long as at least one feature is active, and disappears when everything is off.

If you can't see the overlay, switch the game to **borderless or windowed** mode.

## Troubleshooting

| Problem | Fix |
|---|---|
| Keys do nothing | Check that **NumLock is ON**, Cheat Engine is attached to the game, and the table is loaded. |
| A feature turns itself off right after enabling | The hook could not be installed. Make sure Cheat Engine is attached to the game and you are in Career Mode, then press the key again. |
| Money, Weekly Points or Fitness do not change right away | These values apply when the game updates them. Open a menu or continue the Career schedule so the game writes them again. |
| Stamina has no effect | Press `NUMPAD 1`, `2` or `3` to choose a side. Try `NUMPAD 3` (BOTH) if you are not sure which side you are on. |
| No overlay appears | Switch the game to borderless or windowed mode. |
| Hooks seem stuck | Restart the game, reattach Cheat Engine, and reload the table. |
